# Loom Web — Showcase interactivo (`loom.nsma.dev`)

Sitio oficial de presentación para **Loom (Telar)**, construido con Astro 5, React 19, Tailwind CSS v4, Three.js (shader GLSL interactivo), GSAP ScrollTrigger y Lenis.

- Producción: https://loom.nsma.dev
- Repositorio principal: https://github.com/NormanSMA/Loom
- Hub compañero: https://github.com/NormanSMA/ClaudeHub

## Comandos locales

```bash
pnpm install
pnpm dev
pnpm typecheck
pnpm build
pnpm preview
```
